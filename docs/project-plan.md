# 大模型与健康分层：以 NHIS 为基准的分析 Agent 项目计划

Nov 14, 2026 · Yujia Li

## 摘要

本项目测量大模型对美国成年人健康分层的判断有多准确，并把这项测量做成一个可核验的分析 Agent。基准来自 NHIS 2024 年成人样本公开文件，按复杂抽样设计估计。模型只拿到人口学类别的组合，不接触任何数据。

Agent 对每个研究问题同时给出调查估计和模型判断，并报告两者的差距。第一阶段完成自评健康一个结局。后续阶段加入就医费用障碍、移民与健康两个场景，中国数据留作扩展。

## 1 研究动机与目标

大模型对“哪些人更可能不健康”带有一套隐含的判断，这套判断是否符合真实的人口分布，目前需要用调查数据来检验。健康随教育、收入等社会条件呈现梯度，是健康社会学长期记录的现象，根本原因理论对此有系统的解释（Link and Phelan 1995）。模型如果偏离这一分布，可能夸大群体差异，也可能把差异抹平。

已有研究用调查数据检验过模型能否模拟人的回答，对象主要是政治态度（Argyle et al. 2023）。Bisbee 等人（2024）发现，模型生成的回答变异偏小，回归系数也常与调查估计不同。健康分层方面是否已有同类检验，将在第一阶段做一次文献核查后确认。

项目有三个目标：

1. 按复杂抽样设计，得到健康分层的基准估计。
2. 测量模型判断与基准的差距，包括水平、梯度和稳定性。
3. 把整个流程做成 Agent 和公开网站，使每个结果都能追溯到变量、样本和方法。

项目服务于研究分析。它不提供个体诊断或治疗建议，也不主张用模型代替调查。

## 2 研究问题

项目回答四个问题，都以调查估计及其置信区间为参照。

1. **水平**：模型对各群体“自评健康为一般或较差”比例的判断，与 NHIS 估计相差多少个百分点。
2. **梯度**：模型呈现的教育梯度和收入梯度，比调查估计更陡、更平，还是方向相反。
3. **群体**：哪些群体的偏差最大，教育与族裔交叉的群体偏差是否更大。
4. **稳定性**：更换提问措辞、重复运行或更换模型之后，前三个问题的结论是否改变。

结论由数据决定。项目不预设模型一定夸大差异，也不预设它一定抹平差异。

## 3 数据与第一阶段范围

首版固定使用 NHIS 2024 年成人样本（Sample Adult）公开文件，只用这一个年份。NHIS 是美国国家卫生统计中心（NCHS）开展的住户访谈调查，对象是非机构居住的平民人口。公开文件和文档在 [NCHS 官网](https://www.cdc.gov/nchs/nhis/documentation/2024-nhis.html)直接下载，不需要申请。

分析人群是 25 至 64 岁的成年人。25 岁以上教育大多已经完成。上限取 64 岁，聚焦劳动年龄人口。

| 作用 | 变量 | 含义 | 处理方式 |
| --- | --- | --- | --- |
| 结局 | PHSTAT\_A | 总体健康状况自评 | 保留原始分布，另构造“一般或较差”二分指标 |
| 分层 | EDUCP\_A | 教育程度 | 合并为四组 |
| 分层 | POVRATTC\_A、RATCAT\_A | 家庭收入与贫困线之比 | 按登记的切点分组 |
| 分层 | HISPALLP\_A | 种族与西语裔 | 按文件类别合并 |
| 协变量 | AGEP\_A、SEX\_A、REGION | 年龄、性别、地区 | 年龄分组 |
| 抽样设计 | WTFA\_A、PSTRAT、PPSU | 年度最终权重、伪分层、伪抽样单元 | 建立调查设计对象 |
| 阶段二结局 | MEDDL12M\_A、MEDNG12M\_A | 因费用延迟就医、因费用未就医 | 阶段二加入 |
| 阶段三分层 | NATUSBORN\_A、YRSINUS\_A | 是否出生在美国、来美年限 | 阶段三加入 |

变量名取自 [2023 年成人样本公开文件的变量清单](https://ftp.cdc.gov/Pub/Health_Statistics/NCHS/Dataset_Documentation/NHIS/2023/Adult-summary.pdf)。2024 年文件的变量名、编码和适用人群，在阶段一对照 2024 年 codebook 逐项核对，以 codebook 为准。

两件事在阶段一确定：

- **收入变量**：NHIS 另有收入的多重插补文件。首版用成人文件中的收入变量，还是改用插补文件，按 NCHS 文档决定。
- **分组规则**：教育、收入、族裔和年龄的分组，在看到任何结果之前登记。

首版不做多年合并和趋势分析，不使用受限数据，不做因果推断。

## 4 研究设计

设计分两条线：调查基准线算出真实分布，模型测量线记录模型的判断，最后用同一组指标比较。

### 4.1 调查基准线

- 用 WTFA\_A、PSTRAT、PPSU 建立调查设计对象。年龄限制按子总体方式处理，不直接删除样本。
- 估计各群体“自评健康为一般或较差”的加权比例和 95% 置信区间。先做单一维度：教育、收入、族裔、性别、年龄组。再做教育与族裔的交叉。
- 拟合加权 logistic 回归。结局是“一般或较差”，自变量是教育、收入、族裔、性别和年龄组。
- 每个估计同时报告未加权样本数。未加权样本数低于登记下限的群体不参与比较，下限拟定为 100。

### 4.2 模型测量线

模型不接触任何数据文件。测量用两种提问方式。

**汇总提问（阶段一）**。直接问模型某个群体的比例，要求给出一个数值。例如：在美国 25 至 64 岁、未完成高中的成年人中，有百分之多少的人自评健康为一般或较差。

**画像模拟（阶段二）**。给模型一组类别特征：年龄组、性别、族裔、教育、收入组。用 NHIS 问卷的原题让它以这个人的身份作答。每个类别组合重复多次，再按调查估计的人口份额加权汇总。对模拟结果拟合与 4.1 相同的回归。

画像由类别组合生成，不使用个体记录。组合的人口份额来自调查的加权估计。这样任何个体数据都不会发送给模型服务。

控制条件：

- 提问用英文，与 NHIS 问卷的语言一致。
- 每个提问重复运行，拟定 5 次。提问措辞准备多个版本，拟定 3 个。
- 至少测两个大模型。记录模型名称、版本、调用日期和参数。
- 关闭联网和检索功能。测的是模型自身的判断。

### 4.3 比较指标

| 指标 | 定义 | 对应问题 |
| --- | --- | --- |
| 水平差距 | 模型判断减调查估计，单位为百分点。同时标记模型判断是否落在调查的 95% 置信区间内 | 1 |
| 梯度差距 | 最低组与最高组之间的比例差，模型值与调查值相比。画像模拟另比较回归系数 | 2 |
| 群体差距 | 各群体水平差距的绝对值，按大小排序 | 3 |
| 离散程度 | 画像模拟中各选项的分布，与调查分布对比 | 2、4 |
| 稳定性 | 同一提问重复运行的波动，以及不同措辞、不同模型之间的差异 | 4 |

阶段三加入一个统计基线：用 2023 年 NHIS 拟合的 logistic 模型预测 2024 年各群体的比例。它说明只用上一年数据能做到多准，为模型的误差提供参照。

## 5 系统设计

Agent 把一个自然语言问题同时送进调查基准线和模型测量线，两条线在比较环节汇合。

&#91;embedded content: Agent 流程 · 两条线，六个模块\]

语言模型负责理解问题和组织解释，计算全部由固定的统计程序完成。问题超出已登记的范围时，Agent 说明缺少什么并停止。

| 模块 | 可核验的产物 |
| --- | --- |
| 问题与变量映射 | 结构化分析规格、待澄清事项 |
| 数据与设计核验 | 样本筛选流程、缺失处理记录 |
| 统计执行 | 估计值、标准误、置信区间、未加权样本数 |
| 提问构造与模型调用 | 提问文本、模型版本、原始回答 |
| 比较与核验 | 指标表、结果检查表 |
| 报告与记录 | 方法说明、图表、可复现脚本、运行日志 |

实现上，Python 负责编排流程和保存记录。R 的 survey 包执行复杂抽样分析。独立参考脚本用 Stata 的 svy 命令。网站用 Streamlit 搭建。

## 6 必须落实的分析规则

这些规则写进 Agent 的强制检查。检查不通过时，结果不进入报告。

**样本与缺失**

- 拒答、不知道和未确定分别编码，不并入任何实质类别。缺失不当作健康。
- 每个结果同时给出未加权样本数和加权估计，并写明分母是谁。

**抽样设计**

- 所有估计都通过调查设计对象计算。子总体分析保留完整的设计信息。
- 未调整模型与调整模型使用同一分析样本，样本损失另行报告。
- 记录模型是否收敛，分组是否过于稀疏。

**提问**

- 提问文本、选项顺序和重复次数在运行前登记。之后的任何修改都记为新版本，旧结果保留。
- 模型拒答或答非所问的情况单独计数。不丢弃，也不反复重试到满意为止。
- 语言模型不能更改分组、筛选条件或模型设定。

**解释**

- 横截面结果只解释为关联。统计不显著不等于不存在关联。
- 模型判断接近调查估计，不表示模型可以代替调查。
- “一般或较差”是研究中构造的指标，不表述为临床诊断。

## 7 验证与评估

验证分三层，先保证调查基准正确，再评估 Agent。

1. **独立参考脚本**。同一份分析规格用 Stata 的 svy 命令另写一遍，不调用 Agent 的统计实现。R 与 Stata 的样本数必须完全一致，估计值和置信区间在登记的容差内一致。
2. **外部对照**。NCHS 公布了基于 NHIS 的交互式汇总统计，可按教育、家庭收入、种族和西语裔等分组查看成人健康指标（[技术说明](https://wwwn.cdc.gov/NHISDataQueryTool/SHS_adult/SHS_Tech_Notes_6.27.25.pdf)）。对齐年份、年龄范围和分组定义之后，用它核对参考脚本的估计。定义对不齐的指标不做比对。
3. **Agent 测试题**。三类题各 8 题，一半用于开发，一半保留评估。保留题在开发开始前写好并封存。

| 题型 | 题数 | 检查内容 |
| --- | --- | --- |
| 描述与分组比较 | 8 | 人群筛选、变量编码、权重、分母、比例和置信区间 |
| 回归 | 8 | 协变量、参考组、同一分析样本、估计与报告一致 |
| 澄清与能力边界 | 8 | 模糊口径、缺失变量、因果要求、稀疏样本 |

每题重复运行 3 次。样本、测量、抽样设计、统计结果和报告全部满足要求，才算正确。对必须澄清或无法支持的题，正确澄清或停止也算正确。题量只够首轮验证，不用来判断泛化能力。

### 首版完成标准

- NHIS 2024 的数据字典和抽样设计核验完成。
- R 与 Stata 参考脚本结果一致，并通过外部对照。
- 自评健康、汇总提问、一个模型的结果完成，包含重复运行。
- 网站上线，展示对比图和方法说明，并如实标注各部分的完成状态。
- 强制检查失败的结果没有进入报告。

## 9 预期产出

项目交付四样东西：

- **Agent 原型**：输入自然语言问题，输出调查估计、模型判断、两者差距和方法说明。
- **公开网站**：展示各群体的对比图、方法说明和各场景的完成状态。只展示汇总结果。
- **代码仓库**：数据字典、R 与 Stata 参考脚本、提问文本、运行记录。
- **方法报告**：设计、结果、逐题评估和失败案例。

内容上覆盖三个场景：社会经济地位与自评健康、就医费用障碍、移民与健康。

项目的贡献有两点。第一，把健康分层研究中的测量和统计判断落实为可检查的流程。第二，提供模型判断与调查估计之间差距的证据，包括差距出现在哪些群体。

## 10 局限与边界

项目测量的是模型“知道什么”，不检验它预测未知数据的能力。具体的局限有六点：

- **训练数据**：模型可能在训练中见过 NCHS 公布的统计数字。模型答得准，可能来自记忆。
- **时效**：结果只对所测的模型版本和调用日期成立。模型更新后需要重测。
- **两种提问方式**：汇总提问和画像模拟测到的内容不同，结论可能不一致。两者分别报告。
- **类别组合**：画像只含几个类别特征，丢掉了个体层面的其他信息。
- **公开文件**：NCHS 为保护隐私，对公开文件中的部分变量做了删减或编辑。细分群体的分析可能受限。
- **测试题量**：Agent 的测试题少，评估结果不能推广到其他数据。

自评健康是主观报告。所有结果都是横截面的描述和关联，不支持因果结论。
